# Data access

Participant-level data are not distributed in this repository because the consent and confidentiality conditions do not permit unrestricted public release.

Data are, in principle, available to qualified scientific researchers affiliated with non-commercial research organizations worldwide. Requests must include the research questions, methodology, and intended statistical analyses and can be submitted through the [data-sharing request form](https://redcap.link/data_sharing). Applications are reviewed by the study principal investigators, typically within six to eight weeks.

Approved users must store the supplied files outside version control. The expected local filenames and configuration variables are documented in `README.md` and `config.example.env`.

This repository contains no participant-level data, derived participant-level z-score tables, assignment tables, or fitted pickle objects.
